# Security Policy

## Reporting a Vulnerability

Please open a private report or contact the repository maintainer directly if you find a security issue.

Do not publish real child data, API keys, reset tokens, MongoDB credentials, or screenshots containing private learner information in public issues.

## Sensitive Data

- Keep `.env` files local.
- Use `backend/.env.example` and `.env.example` as templates only.
- Rotate any key that is accidentally committed.
- Treat emotion samples and child profiles as sensitive educational data.

## Safety Notes

AI-Tutor is an educational support tool. It is not a medical diagnostic system and should not be used to diagnose Autism Spectrum Disorder or emotional states.
