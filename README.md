# 🤖 Autism Tutor - AI Learning Companion

A friendly, autism-friendly AI tutor frontend designed specifically for autistic children. Built with React + Vite for a modern, accessible, and calming learning experience.

![Autism Tutor](https://img.shields.io/badge/React-19.2-blue?logo=react)
![Vite-7.3](https://img.shields.io/badge/Vite-7.3-purple?logo=vite)

## ✨ Features

### For Autistic Children 🎈
- **💬 Chat with AI** - Interactive conversations with a friendly AI tutor
- **📚 Learning Lessons** - Interactive lessons on colors, numbers, letters, shapes, emotions, and social skills
- **⭐ Earn Stars** - Complete lessons to earn stars and track progress
- **🎁 Rewards System** - Redeem earned stars for fun rewards
- **🎮 Quick Activities** - Easy access to favorite learning activities

### For Parents/Teachers 👨‍👩‍👧‍👦
- **📊 Progress Dashboard** - Track learning progress and activity
- **📈 Skill Charts** - Visual representation of skill development
- **⚙️ Customizable Settings** - Adjust fonts, themes, animations, and more
- **⏱️ Time Controls** - Set daily time limits and break reminders
- **📧 Progress Reports** - Weekly email reports on learning activity

## 🎨 Design Principles

This app follows autism-friendly design principles:
- **Calming Colors** - Soft blues, greens, and pastels to reduce sensory overload
- **Predictable Layout** - Consistent navigation and familiar interface
- **Clear Visual Hierarchy** - Big icons, simple text, plenty of whitespace
- **Minimal Animations** - Optional reduced-motion for those who prefer it
- **Accessibility First** - WCAG compliant with keyboard navigation support

## 🚀 Getting Started

### Prerequisites
- Node.js 16+ 
- npm or yarn

### Installation

```bash
# Navigate to the project directory
cd autism-tutor

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will open at `http://localhost:3000`

### Building for Production

```bash
npm run build
```

The built files will be in the `dist` folder.

## 🎯 Available Lessons

1. **🌈 Learn Colors** - Identify and name basic colors
2. **🔢 Counting 1-10** - Learn to count numbers 1 through 10
3. **🔤 ABC Letters** - Learn alphabet letters with words
4. **🔷 Shape Hunt** - Find and identify different shapes
5. **😊 My Emotions** - Recognize and name feelings
6. **👋 Saying Hello** - Learn social greeting skills

## 🏆 Rewards System

Children earn stars for completing lessons:
- Colors lesson: 5 ⭐
- Numbers lesson: 10 ⭐
- Letters lesson: 10 ⭐
- Shapes lesson: 8 ⭐
- Emotions lesson: 8 ⭐
- Social skills lesson: 5 ⭐

Rewards include virtual stickers, screen time, choosing games, badges, and more!
